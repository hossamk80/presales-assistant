# النشر على Replit

## ⚠️ اقرأ هذا أولاً — نوع النشر يحدّد بقاء بياناتك

كل عمل النظام — المنافسات وتحليلاتها وأقسام العروض ومستودع المعرفة — يعيش في
ملف SQLite واحد على القرص. لذلك **نوع النشر ليس تفصيلاً**:

| نوع النشر | القرص | مناسب؟ |
|---|---|---|
| **Reserved VM** | دائم | ✅ الخيار الصحيح |
| Autoscale | يُمسح عند كل إعادة تشغيل | ❌ ستفقد كل المنافسات |
| Static | لا يشغّل Python أصلاً | ❌ |

ملف `.replit` مضبوط على `deploymentTarget = "vm"`. لا تغيّره إلى `autoscale`
إلا إذا نقلت التخزين إلى قاعدة بيانات خارجية أولاً.

> **ملاحظة على وضع التطوير (Dev / Repl workspace):** القرص هناك دائم أيضاً،
> فالتجريب داخل الـ Repl آمن. الخطر محصور في نوع النشر (Deployment).

---

## 1. الرفع من GitHub

1. ادفع المستودع إلى GitHub (الفرع الذي تريد نشره).
2. في Replit: **Create Repl → Import from GitHub** واختر المستودع.
3. Replit سيقرأ `.replit` و `replit.nix` تلقائياً.

---

## 2. المفتاح والأسرار

لا تضع مفتاح Gemini في الكود ولا في `.replit`. استخدم **Secrets** (🔒 في
الشريط الجانبي لـ Replit):

```
GEMINI_API_KEY = AIza...
```

النظام يقرأه تلقائياً عند الإقلاع. يبقى بإمكانك إدخال مفتاح يدوياً من صفحة
**إعدادات النظام** ليَجُبّ قيمة البيئة لتلك الجلسة فقط.

---

## 3. تثبيت المكتبات

```bash
pip install -r presales_codex_ready/business_analyst/requirements.txt
```

ملف `replit.nix` يتكفّل بحزم النظام:

- `tesseract` + `poppler_utils` — لتشغيل OCR على الكراسات الممسوحة ضوئياً.
- `dejavu_fonts` — خط يدعم العربية، يحتاجه تصدير PDF.

لتفعيل OCR فعلياً أضف أيضاً حزمتَي Python الاختياريتين:

```bash
pip install pytesseract pdf2image
```

> إن لم يجد tesseract اللغة العربية، بدّل `pkgs.tesseract` في `replit.nix`
> إلى `pkgs.tesseract4` (يشمل حزم اللغات كاملة).

---

## 4. التشغيل

اضغط **Run**. الأمر المضبوط في `.replit`:

```bash
streamlit run presales_codex_ready/business_analyst/app.py \
  --server.address 0.0.0.0 --server.port 8501 --server.headless true
```

الربط بـ `0.0.0.0` ضروري — الربط بـ `127.0.0.1` يجعل التطبيق غير مرئي خارج
الحاوية. إعدادات الوكيل و CORS في `.streamlit/config.toml`.

---

## 5. مسار قاعدة البيانات

يُضبط في `.replit` عبر متغيّر البيئة:

```
ANALYST_DB_PATH = "/home/runner/${REPL_SLUG}/data/analyst.db"
```

وُضع خارج شجرة الكود ليسهل ربطه بقرص دائم ولئلا يُمسح مع كل مزامنة من
GitHub. المسار الافتراضي محلياً يبقى `presales_codex_ready/business_analyst/data/analyst.db`.

### النسخ الاحتياطي

الملف مُستثنى من git عمداً (بيانات عطاءات، لا كود). انسخه دورياً:

```bash
cp "$ANALYST_DB_PATH" "backup-$(date +%F).db"
```

أو استخدم **تصدير مساحة العمل (JSON)** من صفحة **إدارة البيانات** داخل
التطبيق لنسخة قابلة للقراءة لكل منافسة.

---

## 6. الخصوصية — اعتبار يتغيّر بالنشر

النظام صُمّم للتشغيل المحلي: بيانات العطاءات لا تغادر الجهاز إلا في استدعاءات
Gemini. **نشره على Replit يغيّر هذا**: كراسات الشروط وملف الشركة ومستودع
المعرفة ستكون على خوادم طرف ثالث.

قبل رفع كراسات حقيقية:

- تأكد أن الـ Repl **خاص (Private)** لا عام.
- راجع ما إذا كانت سياسة شركتك أو شروط الجهة الحكومية تسمح بحفظ وثائق
  المنافسة خارج بنيتكم.
- إن كانت البيانات حسّاسة، التشغيل المحلي يبقى الخيار الأسلم — Replit للعرض
  والتجريب المشترك.

---

## 7. حصر الأعطال الشائعة

| العَرَض | السبب المرجّح |
|---|---|
| صفحة بيضاء أو "connecting…" لا تنتهي | التطبيق يستمع على `127.0.0.1` بدل `0.0.0.0`، أو `enableCORS` مفعّل |
| نص PDF مشوّه أو رفض التصدير | لا يوجد خط عربي — تأكد من `dejavu_fonts` في `replit.nix` |
| كراسة ممسوحة ضوئياً تعطي تحليلاً فارغاً | OCR غير مثبّت: `pip install pytesseract pdf2image` + حزم النظام |
| اختفاء المنافسات بعد النشر | النشر من نوع Autoscale — انقل إلى Reserved VM |
| `⚠️ يرجى إدخال مفتاح Google Gemini API` | لم يُضبط `GEMINI_API_KEY` في Secrets |
