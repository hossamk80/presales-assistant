# `requirements.txt` يعلن **ما** نحتاجه، وهذا الملف يثبّت **أي نسخة** منه ومن

#     pip install -r requirements.txt -c constraints.txt

# نذكر `altair` ولا `urllib3` في أي مكان، وتكسرنا ترقيتهما.
